# InstallOllama 🦙

Let's be honest: setting up Ollama and downloading models via the terminal isn't hard, but doing it manually every single time or explaining it to non-tech friends is a pain. 

**InstallOllama** is a simple, no-nonsense desktop app that handles the entire setup for you. You open it, click a few checkboxes, and it installs everything in the background while you grab a coffee.

---

## 🤔 What does it actually do?

* **Zero Terminal Needed:** You get a clean, dark-mode window instead of a scary command prompt.
* **Pick & Choose:** Select which version you want and tick the models you need (Llama 3, Mistral, Phi 3, etc.).
* **Real Progress Bars:** It reads the terminal outputs in the background so you can actually see the real download percentage and what's currently happening.
* **No UI Freezes:** It runs the heavy lifting on a separate thread, so the app won't crash or freeze while downloading huge 5GB models.
